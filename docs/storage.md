# データの保存先とバックアップ (サーバー)

## 保存先

案件・削除の記録・操作の記録・Telegram の受信箱・ゲームの状態は、
あなたの Google ドライブの **「予定管理データ」** フォルダに、次の5つのファイルとして保存されます。

| ファイル | 中身 |
|---|---|
| `ALL.json` | 案件 |
| `DELETED.json` | 削除した案件の記録 (ほかの端末で復活しないようにするため) |
| `HIST.json` | 操作の記録 (振り返り分析用) |
| `INBOX.json` | Telegram で行った変更の受信箱 |
| `GAME.json` | XP・レベル・連続記録・クエスト |

- 以前は「スクリプト プロパティ」に保存していましたが、合計500KBまでしか入らず、記録が増えると止まってしまうため、移しました
- Telegram のトークンや合言葉などの小さな設定値は、今まで通り「スクリプト プロパティ」にあります
- **このフォルダとファイルは、移動・名前の変更はしてもかまいませんが、削除や中身の書きかえはしないでください**

## 移行 (1回だけ) — やること

ドライブを使うには、Google ドライブの権限を **一度だけ許可** する必要があります。次の順番で進めてください。

1. **GitHub で PR をマージする**
2. **自動公開を待つ** — GitHub の「Actions」タブで「deploy-gas」が終わるまで待ちます (1〜2分)
   - 最後の「公開されたか確認」は、許可が終わるまで赤い ✕ になることがあります。公開自体は終わっているので、そのまま次へ進んでください
3. **Apps Script の画面を開く** — https://script.google.com でプロジェクトを開きます
   - すでに開いていた場合は、**ページを再読み込み** してください (古い内容のままだと権限の確認画面が出ません)
4. **`setup` を実行する** — 上の関数の選択で `setup` を選び、「▶ 実行」を押します
5. **許可する**
   1. 「承認が必要です」と出たら「権限を確認」を押す
   2. 自分の Google アカウントを選ぶ
   3. 「このアプリは Google で確認されていません」と出た時は「詳細」→「(プロジェクト名)(安全ではないページ)に移動」を押す (自分で作ったスクリプトなので問題ありません)
   4. 次の4つを求める画面が出るので、「許可」(または「すべて選択」→「続行」) を押す
      - Google ドライブのファイルの参照・編集・作成・削除 (データとバックアップの保存に使います)
      - 外部サービスへの接続 (Telegram・Gemini に使います)
      - あなたとしてメールを送信 (毎朝のメールに使います)
      - スクリプトの実行時間の管理 (毎朝・1分おき・毎週のトリガーに使います)
6. **結果を確かめる** — 画面下の「実行ログ」に「保存先: Googleドライブ「予定管理データ」」と出れば完了です
   - アプリの「設定」→「☁️ クラウド同期」→「状況を確認」でも、「💾 保存先: Googleドライブ」と出ます
7. (任意) GitHub の「deploy-gas」を「Re-run jobs」で再実行すると ✅ になります

許可するまでの間 (手順2〜5) は、同期・Telegram・毎朝の通知が止まります。
その間に Telegram へ送ったメッセージやボタンは、許可した後にまとめて処理されます。

### 移行の中で行うこと

`setup` は、スクリプト プロパティのデータをドライブへ移します。

1. ドライブにファイルを書く
2. 読み直して、1文字も違わないことを確かめる
3. 確かめられたら保存先を切り替え、スクリプト プロパティの古いデータを消す

途中で失敗した時は、スクリプト プロパティの元のデータには一切触れていないので、今まで通り動きます。
失敗した場合も、30分に1回まで自動で再挑戦します。

## 週ごとのバックアップ

毎週日曜日の深夜2時に、全データを1つの JSON ファイルにまとめて、
ドライブの **「予定管理バックアップ」** フォルダに保存します。

- ファイル名は `yotei-backup-2026-11-01.json` のように日付付きです
- **新しい12週分だけ** 残し、それより古いものは自動でゴミ箱へ移します (ゴミ箱からは30日間元に戻せます)
- Telegram のトークン・Gemini の APIキー・合言葉は、バックアップに **入れません**
- 最後にバックアップした日時は、「状況を確認」に表示されます
- すぐにバックアップしたい時は、Apps Script の画面で関数 **`weeklyBackup`** を選んで ▶ 実行 してください

> アプリ側にも、端末ごとの自動バックアップ (直近10世代) が別にあります (設定 →「↩ バックアップから復元」)。

## うまくいかない時

| 様子 | 直し方 |
|---|---|
| 「状況を確認」で「保存先: スクリプト プロパティ」のまま | Apps Script の画面で `setup` を実行し、権限の確認で「許可」してください。それでも変わらない時は「プロジェクトの設定」→「スクリプト プロパティ」の `STORE_ERROR` に理由が書かれています |
| 同期やTelegramが「承認が必要です」「Authorization is required」で止まる | ドライブを使う権限がまだ許可されていません。Apps Script の画面で `setup` を実行して「許可」してください |
| `setup` を実行しても許可の画面が出ず、「DriveApp.createFolder を呼び出す権限がありません」などと出る | ① Apps Script の画面を再読み込みしてから、もう一度 `setup` を実行してください。② それでも出る時は、左の歯車「プロジェクトの設定」で「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェックを入れ、エディタの `appsscript.json` に `oauthScopes` (drive など4つ) が書かれているか確認してください。書かれていなければ自動公開がまだ終わっていません。③ 書かれているのに出ない時は、https://myaccount.google.com/permissions でこのプロジェクトのアクセスを一度削除してから、`setup` を実行し直してください |
| 「予定管理データ」のファイルを消してしまった | 「予定管理バックアップ」の最新ファイル、またはアプリの「↩ バックアップから復元」で戻せます。困ったら、作業をお願いする時にそのファイルを渡してください |
